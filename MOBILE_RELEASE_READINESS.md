# Mobile release readiness

## Local Android build

BF-Portal uses Node 22, Java 17, and Gradle 8.13. Run the web checks and sync before invoking system Gradle:

```sh
npm ci
npm run typecheck
npm run test:ci
npm run build
npx cap sync android
(cd android && gradle assembleDebug)
```

The Gradle wrapper scripts and text properties are retained for developer convenience, but the binary wrapper JAR is intentionally untracked. A developer with Gradle installed may regenerate it with `gradle wrapper`; the generated JAR must remain untracked. CI installs Gradle explicitly and calls `gradle`, not `./gradlew`.

## BF PORTAL ANDROID

### READY

- Capacitor Android project
- Application identifier `com.boreal.portal`
- Compile and target API 36 (minimum API 24)
- HTTPS-only release networking
- Existing shared `bfportal://` deep-link routing
- Android system-back navigation and native lifecycle handling
- Credential-free debug build
- System document chooser support through Capacitor's WebView file input handling; source document workflows remain shared with web/PWA
- Responsive WebView resizing through the standard Capacitor activity configuration (no fixed phone/tablet dimensions)

### NEEDS CREDENTIALS

- Firebase configuration (`google-services.json` is intentionally absent and optional for debug builds)
- Production push and a server-side device-token registration capability
- Play signing key
- Native secure credential-storage plugin and migration: current web storage behavior is preserved to avoid breaking login; production native auth must use iOS Keychain and Android Keystore-backed encrypted storage through the centralized auth-token boundary

### NEEDS MANUAL ASSET

- Production launcher icon artwork
- Adaptive icon artwork
- Round icon artwork
- Monochrome icon artwork
- Final production splash branding

Development builds temporarily use Android's system application icon and a solid navy splash theme. No production artwork is included.

### NEEDS MANUAL STORE SETUP

- Google Play application
- Signed AAB
- Data Safety declaration
- Screenshots
- Store listing

## Security and platform boundaries

- Android declares only internet and notification permissions; it does not request legacy/broad storage, camera, or microphone access.
- Cleartext traffic is disabled application-wide. No permissive network security configuration is present.
- Firebase activation is conditional on a real `google-services.json`; credentials and signing material are ignored.
- Widget publishing and App Group persistence remain iOS-only. Staff authentication is never placed in widget/App Group storage.
- Copied Capacitor web assets are generated by `npx cap sync` and remain untracked.
