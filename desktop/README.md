# Boreal Staff Portal — macOS desktop app

An Electron shell around https://staff.boreal.financial. It loads the live
origin rather than a bundled build, so MSAL redirects, OTP login and API calls
behave exactly as they do in a browser, and the app never needs rebuilding when
the portal deploys.

## Build the .app

    cd desktop
    npm install
    npm run dist

The unsigned DMG lands in `desktop/release/`. Because there is no Apple
Developer account attached, macOS will refuse the first launch: right-click the
app in Applications and choose Open, then confirm. That is a one-time step —
after that it opens normally, and it does not expire.

## Run it without packaging

    cd desktop
    npm install
    npm start

Point it somewhere else with `BOREAL_PORTAL_URL=http://localhost:5173 npm start`.

## Why not Mac Catalyst

The Capacitor iOS project cannot target Catalyst. `CapApp-SPM/Package.swift`
declares `platforms: [.iOS(.v15)]`, the file is regenerated by the Capacitor
CLI on every sync so editing it does not stick, and Catalyst support is an open
upstream feature request rather than a shipped feature.

## Windows (BF_PORTAL_DESKTOP_APP_v718)

On Windows the app stays running in the system tray when its window is closed,
so the dialler stays connected and incoming calls ring on the PC and the iPhone
dialler together. It starts at Windows sign-in (hidden in the tray) and updates
itself from this repo's GitHub releases.

To publish a new Windows version, raise `version` in `desktop/package.json`, then
run GitHub Actions > **Desktop app (Windows)** > **Run workflow**. The installer
appears under Releases (`Boreal-Staff-Portal-Setup-<version>.exe`). It is not
code-signed yet, so the first install shows a SmartScreen **More info > Run
anyway** prompt once. Quit from the tray icon to stop calls ringing on that PC.
